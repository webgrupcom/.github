## Client work

Corporate websites, hotel and resort sites, WooCommerce stores, and custom tools such as NFC-based artwork authentication, all designed, built and hosted by us.

## How we build

- **Web:** Next.js, React, TypeScript, Tailwind CSS
- **Backend:** .NET (C#), Node.js, PostgreSQL with row-level security, Redis
- **Mobile:** Swift and SwiftUI, Kotlin, Flutter, Expo
- **Infrastructure:** Docker, Coolify, PostgreSQL high availability with Patroni, Cloudflare (CDN, Load Balancing, Workers, R2), GitHub Actions
